# Build Your Festival – Eco Minigame System (OntdekFabriek)

## Project Description
Build Your Festival is an interactive, festival-themed mobile application designed to teach young users (around 14 years old) about sustainability in a fun and engaging way.

The app consists of a collection of mini games where players take on different roles within a festival environment (e.g., stage setup, waste management, food, hangout areas). Through these games, users learn how everyday decisions at festivals impact the environment.

By combining gameplay, decision-making, and visual feedback, the app encourages players to make more sustainable choices while understanding real-world festival operations.

## Features
Multiple Mini Games
- Hangout
- Food
- Toilet
- Waste (currently under development)
- Stage (currently under development)

- Eco Scoring System
- Visual & Audio Feedback
- Role-Based Gameplay
